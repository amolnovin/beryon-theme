# قالب جدید وب‌سایت بریون (Beryon) — شرکت بریان گوشت آمل

قالب استاتیک، استاندارد، مدرن و کاملاً ریسپانسیو (HTML + CSS + JS خالص، بدون فریم‌ورک) با جهت RTL و زبان فارسی.
طراحی بر اساس هویت بصری قالب پیشین (رنگ قرمز برند + نوار/روبانی یادآور لوگو) و با الگوبرداری از ساختار ۱۰ سایت برتر فارسی حوزه فرآورده‌های گوشتی (کاله/سولیکو، تانیس، آندره، گوشتیران، میکائیلیان، ۲۰۲، بوفالو، شام‌شام، نوپرو، دارا).

## ساختار فایل‌ها
```

├── cat-jambon.html       دسته‌بندی ژامبون

├── about.html            درباره ما (تاریخچه + تایم‌لاین)
├── ceo.html              معرفی مدیرعامل
├── org-chart.html        چارت سازمانی
├── certificates.html     گواهینامه‌ها و افتخارات
```

## نکات فنی و سئو
- `lang="fa" dir="rtl"`، فونت وزیرمتن (Google Fonts) با فال‌بک سیستمی.
- برای هر صفحه: title و meta description یکتا، canonical، Open Graph/Twitter، favicon از لوگوی بریون.
- داده ساختاریافته JSON-LD: سازمان/کسب‌وکار (FoodEstablishment)، BreadcrumbList در همه صفحات داخلی، Product در تک‌صفحه محصول، Article در تک‌نوشته.
- HTML معنایی (header/nav/main/section/article/aside/footer)، تک‌h1 در هر صفحه، alt برای همه تصاویر، skip-link، aria برای منو/تب/آکاردئون.
- robots.txt و sitemap.xml با lastmod.
- بدون فروش آنلاین (مطابق نیاز): CTAها به استعلام قیمت عمده و فرم نمایندگی می‌روند.
- فرم‌ها فعلاً سمت کلاینت اعتبارسنجی می‌شوند و پس از ارسال، پنل موفقیت با کد پیگیری (مانند سایت فعلی) نمایش می‌دهند؛ برای اتصال به وردپرس/بک‌اند، کافی است `action` فرم‌ها یا یک fetch جایگزین preventDefault در `main.js` شود.

## نگهداری و توسعه
- صفحات از طریق اسکریپت `build_theme.py` (بیرون پوشه قالب) از روی `_src/partials` و `_src/pages` ساخته می‌شوند؛ فهرست محصولات در همان اسکریپت است و گریدها خودکار تولید می‌شوند. پس از هر تغییر محتوا: `python3 build_theme.py`.
- استایل و جاوااسکریپت مستقیماً در `assets/` editable هستند.
- breakpoints: ‏1180 / 1020 / 760 / 560 پیکسل + پشتیبانی `prefers-reduced-motion` و استایل چاپ.

## موارد قابل تکمیل در فاز بعد
- تصویر `assets/img/blog-3.jpg` فعلاً جایگزین موقت است (سهمیه تولید تصویر در همان نوبت تمام شد) — در نوبت بعدی بازتولید می‌شود.
- اتصال فرم‌ها به بک‌اند/وردپرس، افزودن PDF واقعی کاتالوگ، و جایگذاری تصاویر واقعی گواهینامه‌ها در صورت تمایل.
