4. نام پوشه بسته باید با پوشه قالب روی سایت یکی باشد، وگرنه قالب دوم نصب می‌شود. جایگزینی پوشه، پشتیبان‌های `public/patches/backups` را پاک می‌کند.

**آزموده‌نشده**

5. سایت زنده، MySQL/MariaDB، Apache/Nginx، بارگذاری از فرم، Safari / Firefox / iOS، ووکامرسِ فعال، چندسایتی، پیوند یکتای ساده.

**رفتارهای شناخته‌شده که عوض نشد**
